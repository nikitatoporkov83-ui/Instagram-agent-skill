# Visual assets

`vice-city-hero.png` is an original AI-generated illustration created for
insta.studio. It depicts a fictional neon waterfront, palm trees and a retro
car at sunset, inspired by the atmosphere of Vice City. It does not contain
official GTA artwork or logos.

`oswald.ttf` and `manrope.ttf` are variable fonts from
[Google Fonts](https://github.com/google/fonts), distributed under the
SIL Open Font License. See `oswald-OFL.txt` and `manrope-OFL.txt`.

The site serves these files locally. The standalone HTML embeds the image and
fonts so that its tools remain available without a network connection.
