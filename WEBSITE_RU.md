# insta.studio — образец сайта

Русскоязычная веб-студия на основе Instagram Agent Skill. Сайт работает без
сервера, API-ключей и установки пакетов. Все тексты обрабатываются в браузере.

## Открыть образец

Откройте `dist/instagram-studio.html` обычным браузером. Это один автономный
HTML-файл, в котором находятся оформление, логика и исходные инструкции навыков.
Архив `dist/instagram-studio.zip` содержит тот же образец, лицензию и эту инструкцию.

В среде разработки можно открыть `web/index.html` или запустить статический сервер:

```bash
cd /workspace/-
python3 -m http.server 4173 --bind 127.0.0.1 --directory web
```

## Что работает

- Главная страница с выбором формата и интерактивной проверкой хука.
- Студия: оценка хуков, тайминг сценария, проверка подписи, очистка текста,
  панель оценки стиля и разбор вручную собранной таблицы Reels.
- Все 13 навыков и 26 формул из исходного проекта.
- Сборка брифов для AI-агента с вашими данными и полным текстом нужного навыка.
- Профиль голоса, черновики и контент-план с сохранением в localStorage браузера.
- Копирование результатов и скачивание TXT/Markdown.
- Адаптивные версии для компьютера и телефона.

Внешняя AI-модель не подключена. Навыки, которые требуют генерации содержания,
формируют полноценный бриф для агента, а не выдают шаблон за результат модели.
Аккаунт Instagram не подключается, автоматическая публикация не выполняется.
Скрипты анализа перенесены в JavaScript, их константы и словари собираются из
канонических Python-файлов. Качество текста и тайминг оцениваются для английского.
Для русского доступны брифы, планирование, черновики и очистка типографики.

Сохранённые данные привязаны к браузеру и адресу страницы. При переходе с
HTML-файла на размещённый сайт или другой адрес хранилище будет другим.
Экспортируйте важные материалы кнопками скачивания. Если localStorage недоступен,
приложение сообщает об этом; текущий результат можно скачать.

## Изменение и проверка

Редактируйте `web/index.html`, `web/styles.css`, `web/app.js`, `web/engine.js`.
`web/data.js` генерируется из оригинальных JSON и SKILL.md. После изменений:

```bash
python3 scripts/build_site.py
node --check web/engine.js
node --check web/app.js
python3 -m unittest discover -s tests -v
```

Для браузерных проверок используется установленный в облачной среде Playwright
и Chromium. Это средства разработки, для открытия готового образца они не нужны.
Сравнительные тесты JavaScript-инструментов также используют Node.js 18+.
В управляемом Chromium политика среды блокирует адреса `file://`; автономный
образец проверяется через локальную загрузку одного HTML с последующим
отключением сети. После загрузки все действия работают без сетевых запросов.

## Размещение на GitHub Pages

Автоматический процесс `.github/workflows/static.yml` проверяет проект и размещает
именно `web/`. Ручной процесс `.github/workflows/pages.yml` также сохранён.
Исходные оформление и инструменты не заменяются другим шаблоном.

Для первого размещения у репозитория должен быть включён GitHub Pages с источником
**GitHub Actions**. Это настраивается в **Settings → Pages → Build and deployment**
или через GitHub API пользователем с нужными правами. Затем запустите
**Actions → Publish insta.studio → Run workflow** для ветки `main`.

Процесс сначала собирает автономный образец и выполняет тесты, затем передаёт
папку `web/` в GitHub Pages. После успешного завершения ожидаемый адрес:
`https://nikitatoporkov83-ui.github.io/Instagram-agent-skill/`.
Ссылка сама по себе не подтверждает доступность: проверяйте результат запуска
и загрузку сайта. Изменения в `main` запускают стандартный процесс автоматически.
ZIP и автономный HTML доступны в артефакте `insta-studio-offline` ручного процесса.

Инструменты Sites в этой сессии отсутствуют. Размещение выполняется через
выбранный пользователем GitHub Pages; автономный HTML также не требует backend.
