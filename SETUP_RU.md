## Проверка

В облачной среде сначала перейдите в каталог проекта:

```bash
cd /workspace/-
python3 --version
python3 -m unittest discover -s tests -v
```

На другой машине команды выполняются из корня скачанного проекта.
Тесты запускают все шесть инструментов на тестовых текстах, проверяют
коды завершения, вычисления, JSON, экспорт Markdown и доступность навыков.
Тестовые данные не отправляются в сеть, временные файлы удаляются автоматически.

## Использование

Пример оценки начала ролика, который можно выполнить сразу:

```bash
python3 skills/ig-reel/hookscore.py --hook 'I lost $18,000 on one missing contract.'
```

Команды для собственных файлов; пути к ним задаются от текущего каталога:

```bash
python3 skills/ig-reel/hookscore.py hooks.txt
python3 skills/ig-reel/beats.py script.txt --target 30
python3 skills/ig-caption/caption.py caption.txt --keywords 'client contracts,freelance pricing'
python3 skills/ig-human/humanize.py draft.txt -o clean.txt --report
python3 skills/ig-human/detect.py draft.txt clean.txt
python3 skills/ig-viral/swipe.py captured.tsv --out .instagram/swipe.md
```

`detect.py`, `hookscore.py` и `caption.py` могут завершаться с кодом `1`,
когда текст требует доработки. Это результат оценки, а не ошибка установки.
Смотрите вердикт и замечания. Режим `--json` предназначен для обработки
результата программой; у `hookscore.py` и `detect.py` в этом режиме код `0`
также возможен при слабом тексте, поэтому проверяйте поле `verdict`.

Для `swipe.py` нужен TSV с целыми числовыми значениями, без сокращений `12k`:

```text
account	followers	median	views	hook
@example	4000	1000	60000	Nobody tells you that your first 30 reels are supposed to flop.
```

Числа в примере синтетические. Замените их собственными данными. Между
столбцами нужны символы табуляции. `median` — обычное число просмотров
конкретного аккаунта; без него инструмент использует число подписчиков.

## Подключение навыков и профиль

Все 13 навыков подключены к проекту относительными ссылками:

- `.agents/skills/ig-*` — обнаружение навыков Codex;
- `.claude/skills/ig-*` — обнаружение навыков Claude Code;
- `skills/ig-*` — единственный экземпляр исходных файлов каждого навыка.

Если текущая сессия была открыта до появления файлов, начните новую сессию
агента в этом проекте, чтобы обновить список навыков. Python-команды работают
сразу. Сохранены и исходные метаданные Claude-плагина в `.claude-plugin/`.

Профиль голоса и рабочие материалы в этом проекте находятся в `.instagram/`.
Этот каталог исключён из Git. Создать шаблон без перезаписи существующего файла:

```bash
python3 - <<'PY'
from pathlib import Path
folder = Path('.instagram')
folder.mkdir(exist_ok=True)
voice = folder / 'voice.md'
if not voice.exists():
    voice.write_bytes(Path('templates/voice.md').read_bytes())
PY
```

Заполните `.instagram/voice.md` своими примерами, аудиторией и фактами перед
созданием персонализированного контента. `AGENTS.md` задаёт локальное
соответствие для путей `~/.claude/instagram/`, указанных в исходных навыках.

## Возможности и ограничения

- Навыки готовят тексты и планы. Они не подключают аккаунт и не публикуют
  посты, комментарии или сообщения в Instagram.
- Лексика, распознавание конструкций и подсчёт слов в Python-инструментах
  рассчитаны на английский. Для русского текста эти оценки и тайминги
  не проверены и могут быть неверными.
- Данные для анализа передаются пользователем. Пример с `yt-dlp` в `ig-viral`
  — отдельный необязательный способ работы с YouTube. Для базового набора
  он не нужен и здесь не установлен.
- Claude Code и Codex обнаруживают навыки через свои механизмы. Наличие
  файлов и ссылок проверяется тестами; интерфейс команд конкретного клиента
  проверяется уже после открытия новой сессии в нём.
